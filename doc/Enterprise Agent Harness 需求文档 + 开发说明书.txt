《Enterprise Agent Harness 需求文档 + 开发说明书》。
我会刻意控制范围：不是做一个几十万行的 Agent 平台，而是做一个 10k～20k LOC 左右、架构完整、企业级特征明显、能够作为简历项目和源码学习项目的 Harness。

Enterprise Agent Harness
基于 DeepAgents + LangChain + LangGraph 构建的企业级 Agent Runtime / Harness
版本：V1.0

一、项目定位
1.1 项目目标
构建一个生产导向的 Enterprise Agent Harness，用于解决企业 Agent 在以下方面的问题：
●  Agent 生命周期管理 
●  多步骤任务编排 
●  Tool 统一治理 
●  Tool 权限控制 
●  Human-in-the-loop 
●  Agent 状态持久化 
●  中断与恢复 
●  Failure Recovery 
●  Replan 
●  SubAgent 
●  Memory / RAG / Context Engineering 
●  Trace / Audit 
●  Evaluation 
●  Agent Version / Governance 
项目不重复实现成熟框架已经提供的能力，而采用：
DeepAgents
    ↓
Agent Capability

LangChain
    ↓
Model / Tool / Middleware 抽象

LangGraph
    ↓
Runtime / State / Checkpoint / Interrupt

Enterprise Agent Harness
    ↓
企业级 Control Plane

七、模块二：DeepAgent Adapter
这是整个项目非常重要的一层。
不要让 Enterprise Harness 到处直接调用：
create_deep_agent()
统一通过：
class AgentRuntime:

    async def run(
        self,
        task,
        context
    ):
        ...
然后：
class DeepAgentRuntime(AgentRuntime):

    def __init__(self, config):
        self.agent = create_deep_agent(
            model=config.model,
            tools=config.tools,
            ...
        )

    async def run(self, task, context):
        ...
这样：
Enterprise Harness
        ↓
AgentRuntime
        ↓
DeepAgentRuntime
        ↓
DeepAgents
未来即使换 Agent Framework：
DeepAgentRuntime
LangGraphRuntime
CustomRuntime
上层都不用变化。
